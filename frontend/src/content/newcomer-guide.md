# 新手导航

> 💡 **食用说明：**
> 这里的名单只提供“线索”，不提供“保姆级教程”。
> 遇到不认识的名词，请复制它，打开大模型（如 ChatGPT、Gemini、DeepSeek、通义千问）并发送如下提示词：
> *" 我是一名大一计算机/物联网相关专业新生，请向我详细介绍【填入名词】，它对我有什么实际用处？我该如何快速上手？"*

## 0. 必修心法：提问的智慧

在向他人提问前，请确保你已经：
1. 搜索或询问 AI；
2. 如果是代码报错，将相关报错信息扔到网上搜索；
3. 仍无法解决时，向他人提问。知道如何清晰描述你的问题（[阅读《提问的智慧》](https://github.com/ryanhanwu/How-To-Ask-Questions-The-Smart-Way)）。

## 1. 开发者军火库

不要把时间浪费在造轮子和配环境上。先学会使用成熟工具，不要把大量时间耗在编辑器选择和重复配环境上。
- **Git & GitHub / Gitee**：版本控制。不会 Git 别碰代码，只要干这一行就逃不掉。
- **AI Agent / 辅助开发工具**（择一上手）：
    - **Trae / Qoder（免费推荐）**: 国内使用比较方便，都有免费版本或试用额度，具体额度经常调整。适合第一次接触 AI 编程工具。但模型能力相对较差。
    - **OpenAI Codex App**：桌面级多智能体指挥中心。支持开多个线程让不同 Agent 并行改代码、互不冲突，适合中大型项目端到端开发。
    - **Claude Code**：Anthropic 出品的终端极客神器。但前段时间爆出使用隐写术标记中国大陆用户，担心有后门的可以用 opencode、codex 代替
    - **OpenCode**：开源 AI 编程工具，个人体验感觉更省 Token。
    - **Cursor / Windsurf**：开箱即用的 AI-IDE。
- **一手文档**：MDN（前端）、Spring Docs（后端）。最权威的来源，不过可能难度较大，直接让 AI 啃好了翻译成人话最好。
- **Google 搜索指令**：熟练运用 `site:`、`filetype:` 等指令搜索。
- **基本运维**：学了一些开发知识好，可以抽空熟悉一下基本的 Linux 命令和 Docker，现在的项目部署基本都离不开容器化。

## 2. 羊毛专区：大学生的数字资产

用好你的学信网和 edu 邮箱（尝试找老师要，或许能要到教育邮箱）。
- **JetBrains 学生包**：免费使用 IDEA、Pycharm、WebStorm 等顶级付费开发工具最新版。
- **GitHub Student Developer Pack**：含各种免费云服务、域名和工具，GitHub Copilot 个人免费订阅。
- **阿里云 / 腾讯云高校计划**：极低成本拥有一台属于自己的云服务器。

### 3.3 算法与逻辑基础

- **力扣 LeetCode：** 新手优先。题目描述清楚，题解和代码质量总体更正常，适合先学会写代码、理解常见算法，也能顺便准备以后找工作。
- **洛谷：** 等力扣刷过一阵子再来。这里更接近正式算法竞赛，要自己处理输入输出，题面也更绕。题解区代码质量参差不齐，不要看到一份能 AC 的代码就照着学。
- **Codeforces：** 再往后的进阶场。适合已经能独立写题，并且想体验限时比赛和真实排名的人。

推荐顺序：**力扣学写代码 → 洛谷熟悉竞赛题面和 ACM 输入输出 → Codeforces 打比赛。**

## 4. 试炼场：值得打的比赛

不要盲目参赛，看准含金量。

### 4.1 算法竞赛类

- **ICPC（国际大学生程序设计竞赛）**：计算机含金量最高的算法比赛。拿奖难度极大，需要极强的算法基础和长期组队训练。咱们学校没参加过🥲，想硬钢的可以三个人组队，联系老师，然后去参加网络预选赛试试水。
- **CCPC（中国大学生程序设计竞赛）**：国内算法赛的“小号 ICPC”。难度和认可度极高，适合有坚实算法基础的同学。咱们学校参加过省赛和邀请赛，截止 2026，最好的成绩是河北省赛银奖、全国邀请赛（河北）铜奖。
- **百度之星**：大厂背书的高质量个人赛。题目难度较高，ACM 赛制，含金量高于普通省赛。学校不组织，自己报名参加就行。
- **天梯赛 (GPLT)**：个人独立做题、团队算总分的算法竞技。题目覆盖广，主考基础和做题速度。2026 年终于参加了一次，以后估计也会继续参加吧。
- **码蹄杯**：难度适中，适合在蓝桥杯之后作为进阶练手。学校不组织，自己报名参加就行。
- **蓝桥杯**：分 C/C++、Java、Python 等组别。算法类普及度最高的比赛，拿省奖不难，适合以赛促学。学校组织，但校赛之类的挺乱的，学自己的然后跟着学校通知报名参加就行。
- **传智杯**：适合大一新生的算法入门赛，难度相对友好，可作为练兵打怪的第一站。AI 说的，我没打过（🥲
- **睿抗机器人开发 - 编程赛道**：据说比蓝桥杯还要简单，没参加过，可以尝试。

> **总结：算法打怪升级路线参考**
>
> - **新手村练级**：传智杯、蓝桥杯（适合大一，门槛低，省奖点击就送）
> - **进阶试炼场**：码蹄杯、天梯赛、百度之星（需要真功夫）
> - **终极 Boss 战**：CCPC、ICPC（难）

### 4.2 综合工程类

不要看着比赛名头大就盲目冲，有些比赛根本不是拼技术的。

- **大创 (大学生创新创业训练计划)**：官方背书，有资金支持。严格来说它是“项目立项”而不是比赛，最适合作为长周期团队项目的孵化器。标准打法是：申请大创拿到经费和名额 $\rightarrow$ 把项目做出来 $\rightarrow$ 拿这个项目去打下面那些比赛。
- **中国大学生计算机设计大赛**：偏综合工程，门槛适中。适合把平时做好的软件系统、AI 应用或物联网软硬结合项目拿去打榜包装。对技术本身的看重程度还可以，投入产出比算正常。
- **挑战杯 / 创新大赛（原“互联网 +”）**：**【高亮避坑】** 这类比赛本质上是“商业路演”，极度依赖导师人脉、学院资源、项目包装（PPT）和现场答辩。**代码实现根本不是唯一重点，甚至经常不是重点**。说句实话：咱们系在这方面基本没什么资源，具体可以问自己导师看看有没有以前的项目可以传承。所以我的建议是：自己做项目锻炼为主，项目做成的话可以顺便参加一个比赛。纯走技术开发路线的同学不要太在意奖项结果。
