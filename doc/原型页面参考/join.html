部门介绍

算法部

部门职责

专注于算法类竞赛的研究与参与，包括ACM、蓝桥杯、数学建模等。通过算法训练提升逻辑思维和问题解决能力，在竞赛中积累经验。

招新要求

  • 对算法和编程有兴趣
  • 愿意学习，有自主学习能力
  • 无技术要求，欢迎大一新生

学习内容

算法竞赛 数据结构 数学建模 C++ Python

项目竞赛部

部门职责

专注于项目类竞赛的参与，包括挑战杯、互联网+、计算机设计大赛、物联网设计大赛等。在做项目中学习技术，通过竞赛提升综合能力。

招新要求

  • 对项目开发和技术学习有兴趣
  • 愿意在项目中学习，有团队协作精神
  • 无技术要求，欢迎大一新生

学习内容

Web开发 移动开发 硬件开发 项目管理 竞赛备赛

综合管理部

部门职责

负责社团的综合管理工作，包括活动策划、宣传推广、资源协调等。通过管理活动提升组织能力和沟通协调能力。

招新要求

  • 对组织管理和活动策划有兴趣
  • 具备良好的沟通能力和责任心
  • 无技术要求，欢迎大一新生

学习内容

活动策划 宣传推广 团队管理 沟通协调

在线报名

常见问题

我们欢迎所有对学习和成长有兴趣的同学加入，特别是大一新生。所有部门都没有技术要求，我们主要看重你的学习意愿和自主学习能力。只要你有热情、愿意学习，我们都非常欢迎你的加入。加入后，我们会提供相应的指导和培训，帮助你在实践中成长。
社团活动主要安排在课余时间，一般每周有1-2次例会或技术分享会，具体时间会根据大部分成员的课程表进行协调。项目开发和竞赛备赛会根据项目进度和竞赛时间灵活安排，尽量不影响大家的正常学习。
加入社团后，你可以： 1. 学习前沿技术知识，提升专业技能； 2. 参与实际项目开发，积累项目经验； 3. 有机会参加各类科技创新竞赛，获得奖项和荣誉； 4. 认识志同道合的同学，建立深厚友谊； 5. 获得实习和就业机会，为未来职业发展打下基础。
选择部门时，可以根据自己的兴趣爱好和职业规划来考虑。如果你专注算法类竞赛，可以选择算法部；如果你更喜欢做项目并参加项目类竞赛，可以选择项目竞赛部；如果你擅长组织管理和活动策划，可以选择综合管理部。所有部门都没有技术要求，主要看重学习意愿和自主学习能力。
招新流程主要包括：线上报名、简单面试、正式加入三个环节。具体时间安排如下： 1. 线上报名：9月1日-9月15日 2. 简单面试：9月16日-9月20日（主要了解学习意愿和自主学习能力） 3. 正式加入：9月21日公布结果 请关注我们的微信公众号获取最新的招新信息和时间安排。
