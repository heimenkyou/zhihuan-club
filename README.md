# 社团招新留言板前端

这是一个基于Vue3 + Vite + TypeScript的现代化留言板应用，用于社团招新活动。

## ✨ 新版本特性

### 🎨 现代化设计
- **渐变背景**: 使用优雅的蓝紫色渐变背景
- **玻璃拟态效果**: 半透明卡片设计，支持背景模糊
- **动画效果**: 悬停动画、加载动画、浮动元素
- **响应式布局**: 完美适配PC端和移动端

### 🚀 用户体验提升
- **卡片式布局**: 每个留言独立成卡片，信息层次清晰
- **头像系统**: 基于用户昵称首字母生成个性化头像
- **智能时间显示**: 相对时间显示（刚刚、5分钟前、2小时前等）
- **状态反馈**: 加载、错误、空数据等状态的友好提示

### 📱 响应式设计
- **移动优先**: 优先考虑移动端体验
- **断点设计**: 480px、768px、1200px 三个主要断点
- **弹性布局**: 使用CSS Grid和Flexbox实现自适应布局
- **触摸友好**: 按钮大小适合触摸操作

## 🔧 技术特性

- **前端框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **语言**: TypeScript
- **状态管理**: Pinia
- **路由**: Vue Router
- **HTTP客户端**: Axios
- **样式**: CSS3 + 现代CSS特性

## 📁 项目结构

```
src/
├── components/          # 公共组件
├── views/              # 页面组件
│   ├── Home.vue        # 首页 - 英雄区域 + 特性展示
│   └── MessageList.vue # 留言列表页 - 现代化卡片布局
├── stores/             # 状态管理
│   └── messageStore.ts # 留言状态管理
├── services/           # API服务
│   ├── api.ts          # HTTP客户端配置
│   └── messageService.ts # 留言相关API
├── router/             # 路由配置
├── assets/             # 静态资源
└── style.css           # 全局样式 + 工具类
```

## 🎯 设计亮点

### 留言卡片设计
- **用户信息区**: 头像 + 昵称 + 时间
- **内容区**: 清晰的留言内容展示
- **交互区**: 点赞按钮 + 删除按钮（权限控制）
- **视觉层次**: 使用阴影、边框、颜色区分不同区域

### 点赞按钮样式
- **未点赞状态**: 白色心形 + 蓝色边框
- **已点赞状态**: 红色心形 + 红色边框
- **悬停效果**: 颜色变化 + 轻微上移
- **动画反馈**: 图标缩放动画

### 删除按钮样式
- **权限控制**: 仅对可删除的留言显示
- **视觉提示**: 红色垃圾桶图标
- **交互反馈**: 悬停时背景色变化 + 缩放效果

```typescript
      target: 'https://club.luowb.cn',
      changeOrigin: true,
      rewrite: (path) => path.replace(/^\/api', '/api')
    }
  }
}
```

## 🎨 设计系统

### 颜色方案
- **主色调**: #667eea (蓝色)
- **辅助色**: #764ba2 (紫色)
- **成功色**: #42b983 (绿色)
- **警告色**: #ff6b6b (红色)
- **中性色**: #7f8c8d (灰色)

### 字体系统
- **主字体**: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto
- **标题**: 600-800 字重
- **正文**: 400 字重
- **辅助文字**: 300 字重

### 间距系统
- **基础单位**: 0.25rem (4px)
- **间距等级**: 1, 2, 3, 4, 5 (对应 4px, 8px, 12px, 16px, 20px)
